\section*{Estado de las referencias}
Se han seleccionado seis fuentes para las secciones de Belinda: cuatro artículos
científicos, un libro académico y un estándar técnico. El fundamento incorpora
las citas correspondientes a los apartados consultados. La bibliografía reúne
las obras efectivamente citadas por el equipo; el estándar TCP se utilizará al
redactar su implementación cuando corresponda.
